# Desenvolvimento de Interfaces

Repositório de estudos e exercícios de HTML, com foco em desenvolvimento 
de interfaces web (Front-End).

## Conteúdo

- `Exemplo1 – Exemplo4` — termos e tags básicas do HTML e como são utilizados.
- `Exemplo5 – Exemplo9` — uso de links e tabelas (tables).
- `Exemplo10 – Exemplo12` — web semântica (tags como header e footer) e 
  formulários, incluindo a diferença entre os métodos GET e POST.
- `Exemplo13 – Exemplo16` — aprofundamento em formulários: uso de div, 
  fieldset, legend, input, checkbox, email, radio, label e textarea. 
  *(em andamento)*
- `Exercicio17` e `Exercicio18` — exercícios feitos de forma independente, 
  sem acompanhamento do professor, para treinar a construção de 
  formulários e consolidar o conteúdo visto até então.

## Tecnologias

HTML

## Aprendizados

Estrutura e semântica do HTML, criação de links e tabelas, tags semânticas 
(header, footer, entre outras), construção de formulários (inputs, 
checkboxes, radio buttons, labels, textarea, fieldset/legend) e diferença 
entre os métodos GET e POST.
