Exemplo 9 - Links e Tabelas

Descrição

Este exemplo mostra como criar tabelas e links em HTML, nele também utilizamos a estrutura da web semântica, que tem um papel muito importante na indexação de conteúdos pelos mecanismos de busca. Neste exemplo estamos usando as tags semânticas <header>,<footer>,<section>,<nav> e <article>

Também utilizamos as tags para criação dos links e tabelas, que são descritos a seguir:

  • <a>Define um hyperlink
  • <table>Define uma tabela
  • <tr>Define o tr define uma linha da tabela- table row
  • <th>Define um cabeçalho da tabela - table header
  • <td>Define uma celula da tabela - table data

Exemplo de links que abrem uma nova aba:

  • visite o Google
  • visite a CNN
  • Explore projetos no Github
  • Veja videos no Youtube
