Exemplo 7 - HTML - Listas

em documento html podemos usar tres listas distintas sao elas: lista ordenada, lista nao ordenada e lista descritiva. Essas listas sao representadas pela tags: <ol>, <ul> e dt/dl/dd. Para todas as listas utilizamos a tag <li>, que representa um item e so pode ser utlizado dentro das listas ordenadas ou nao ordenadas

Lista ordenada - <ol>

Neste tipo de lista os elementos sao distribuidos em ordem, ou seja, a ordem importa. Por exemplo:

  1. Planejamento
  2. Design
  3. Desenvolvimento
  4. Teste
  5. Publicacao

lista nao ordenada - <ul>

Esse tipo de lista nao possui uma ordem especifica e seus elementos sao representados por bullets. Essa lista é muito utilizada para construcao de menus. Por exemplo:

  • HTML
  • CSS
  • Javascript
  • Outras tecnologias

Listas aninhadas

Nesse tipo de lista possuimos sublistas, conforme exemplificamos abaixo:

  3. Desenvolvimento

Listas de descrição

As listas de descrição são muito utilizadas quando precisamos criar glossarios, fichas tecnicas e perguntas frequentes. Abaixo exemplificamos o seu uso.

Wireframe
Esboço que define a disposição dos elementos, sem cores nem tipografia.
Responsividade
Capacidade de a interface se adaptar a diferentes larguras de tela.
