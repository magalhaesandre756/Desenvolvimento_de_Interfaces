Exemplo 20 - HTML CSS - Seletores de Tipo

Seletores CSS

Seletores CSS são padrões que identificam elementos HTML para aplicação de estilos com seletores de tipos, classe e id. Neste exemplo vamos focar no seletor de Tipo

Seletor de Tipo

O seletor de tipo é aquele que é basedado em tags html, tais como p, h1, h2, ul, ol, table, etc. Ou seja, por meio dessse tipo de seletor eu consigo estilizar as tags html correspondentes.
