Exemplo 32 HTML CSS - Box Model

O Box Model ou modelo de caixa é um dos conceitos mais fundamentais do CSS, pois ele retrata ou dita como um elemento HTML será renderizado na tela, determinando o seu tamanho, espaçamento e como ele interagirá com outros elementos.

O Box Model é dividido em 4 camadas, como se fosse uma caixa, neste exemplo estaremos demonstrando cada uma dessas camadas que são:

  1. Content(Conteúdo): é o conteúdo real do elemento, como textos, imagens e ou videos, dentre outros
  2. Padding(Preenchimento): é relacionado ao espaço interno entre o conteudo e a borda da caixa.
  3. Border(Borda): é a linha que envolve o preenchimento é o conteudo da nossa caixa e pode ser exibida de varias formas,
  4. Margin(Margem): a propriedade margem/margin é o espaço transparente ao redor da caixa, e serve para afastar os elementos uns dos outros
