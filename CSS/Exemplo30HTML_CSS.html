Exemplo 30 HTML- CSS (Cores em CSS)

O CSS permite representar cores de diferentes formas. Podemos utilizar o nome a cor, valores hexadecimais,RGB, RGBA, HSL, HSLA, dentre outros.

1. Cores pelo nome

Uma das formas mais simples de utilizar cores em CSS é informando diretamente na propriedade referente a cor o nome da cor.

Este texto utiliza a cor blue.

2. Cores no padrão hexadecimal

o padrao de cores hexadecimal é aquele que usa o simbolo # seguido normalmente de 6 caracteres do sistema hexadecimal que vai do 0 ao 9 e da letra A à F.

Os dois primeiros representam o vermelho, os dois seguintes representam o verde e os dois últimos representam o azul.

Este texto utiliza a cor hexadecimal #8B0000.

Exemplo: color: #8B0000;

3. Padrao de cores RGB

O sistema de cores RGB é aquele baseado nas cores Vermelho(R), Verde(G), Azul(B) Cada uma dessas 3 cores recebe um valor de 0 a 255, onde o 0 é ausencia de cor e o 255 todas as cores.

Alem disso, podemos tambem utilizar um canal de transparencia, chamado alfa, ficando o sistema descrito como RGBA o alfa pode varias entre 0 e 1, onde quanto mais proximo do 0 maior sera a transparencia e mais proximo do 1 menos transparente sera

4. Padrao de cores HSL

O padrao HSL significa HUE,Saturation e lightnes, ou seja, matiz,saturação e luminosidade. a matiz representa a possição da cor no circulo cromatico e normalmente varia de 0 a 360 graus ja a saturação determina a intensidade da cor e é representada por valores percentuais por fim temos a luminosidade que determina o quanto a cor sera clara ou escura e tambem é definida por valores percentuais
