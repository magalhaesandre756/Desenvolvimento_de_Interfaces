Exercício 8 HTML - Uso das tags de Image, Vídeo e IFrame

Este exemplo mostra diferentes formas de usar as tags img, video e iframe, incluindo o uso de figure e figcaption para agrupar mídias com legendas.

Descrição

As tags abordadas são:

  • img: Usada para inserir imagens na página.
  • video: Usada para inserir vídeos na página.
  • iframe: Usada para incorporar conteúdo externo, como vídeos do YouTube.
  • figure: Usada para agrupar mídias (imagens, vídeos, gráficos) com uma legenda.
  • figcaption: Usada para adicionar uma legenda ao conteúdo dentro de figure.
